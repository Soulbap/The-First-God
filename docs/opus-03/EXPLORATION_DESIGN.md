# Utforskning og kamera

1. Lokalt/område: hjemlandet.
2. Sammenhengende rike: verdenskart, der ukjente land fortsatt er skjult.
3. Ekspedisjon: kun oppdagede land kan markeres som besøkt i autoritativ tilstand.
4. Karttegnernes kunst: lesbar sammenstilling av oppdagelser.
5. Luftmåling: planetkamera, men ukjente områder er fortsatt dempet.

Kameraskifte endrer aldri regionressurser, innbyggere eller karavaner.
