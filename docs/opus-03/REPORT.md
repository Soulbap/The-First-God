# OPUS-03 — rapport

Implementert: rebalansert PrP, mer tidlig stein, byggavhengig tomteklarering, vern mot urban tregjenvekst, historisk første ly, kart før planet og sen Luftmåling-gate. SAVE_VERSION er 3; versjon 2 lastes med sikre standarder.

Kontroll: `npm test` — 128/128 bestått. Full visuell capture og menneskelig spilltest er ikke kjørt i denne arbeidsøkten.

Viktig grense: regionbesøk har autoritativ, lagret valgtilstand og er kun tillatt for oppdagede land. En full lokal renderer for fjerne regioner er fortsatt OPUS-04-arbeid; den må ikke beskrives som implementert.
