# Spillteststatus

Automatiske tester besto (128/128). Ingen menneskelig spilltest eller lydlytting ble gjennomført her.

Neste manuelle sjekkliste: PrP etter første Ragnarok, stein ved tre frø, klarering rundt marked, historisk ly, trær ved veier, kart-vs-planet-forståelse og trygg retur fra hvert kameranivå.
