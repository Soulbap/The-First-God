# Videre arbeid

- Full deterministisk lokal scene for hvert besøkt fjernt land, med terreng, utpost og aktivitet projisert fra regional tilstand.
- Faktisk luftfart/aerial surveying som synlig handling, før eventuell satellitt- og romfart.
- Visuell capture, menneskelig spilltest og fler-syklus botmåling med dokumenterte kjøpsstrategier.
