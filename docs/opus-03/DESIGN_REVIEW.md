# Designvalg

- PrP belønner milepæler og faktisk samfunn, mens lang venting gir avtagende uttelling.
- Tett by betyr mindre mellom boliger, ikke mindre plass ved marked, verksted og lager.
- Første ly bevares som minnested, ikke som aktiv primitiv bolig.
- Menneskelig kartkunnskap åpner oversikt før planetkamera; Luftmåling kommer etter Verdens første sivilisasjon og karttegning.
