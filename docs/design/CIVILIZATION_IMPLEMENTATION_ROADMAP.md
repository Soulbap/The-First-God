# Veikart for kontinuerlig sivilisasjon

Dette er avhengighetsbaserte, spillbare vertikale skiver — ikke datoer eller krav om bestemte «aldre». Ingen av dem er startet av denne dokumentasjonsendringen.

## Nåværende OPUS-03

**IMPLEMENTERT:** Genesis til kart/utposter, autonom urban oppgradering, historisk ly, kart før planet, deterministiske besøk og save v3. Før ny stor funksjon skal OPUS-03 først menneskespilltestes og visuell capture-port fullføres, slik eksisterende rapport sier.

| Fase | Mål og gjenbruk | Sløyfe og synlig bevis | Tester / ferdigdefinisjon | Risiko |
|---|---|---|---|---|
| Umiddelbar: OPUS-03 validering | Gjenbruk hele nåværende simulering og capture-verktøy. | Spill fra ly til planetgate; se stein, urban klarering, minnested og trygg kartretur. | Full gjennomspilling, GUI/realm-smoke, faktiske før/etter-bilder og menneskelig sjekkliste. | Ikke starte større system før dette er vurdert. |
| Materialer og matnett | Gjenbruk bygging, ruter, roller og lagring. Legg til én regional metallsløyfe og transportkapasitet. | Gruve/handel → smelteverk → bedre redskap/bygg. | Normal, manglende-malm og fjernhandelsflyt; ingen negative beholdninger; visuell kontroll. | For mange ressurser eller historisk tvangskjede. |
| Kunnskap, kart og navigasjon | Gjenbruk kart, ekspedisjonslogikk og hall. Skill oppdaget fra oppmålt. | Autonome reiser gjør kart mer presist og åpner bedre ruter. | Determinisme, lagre/les, besøk uten ressursduplisering og kamera-retur. | Å gjøre ekspedisjoner manuelle. |
| Mekanisk kraft og tung logistikk | Gjenbruk lokale ressurser/bygg og ruteavstand. | Egnede steder driver møller; kapasitet endrer produksjon/transport. | Input/vedlikehold, alternativ vann/vind, ingen produksjon fra ingenting. | Dekorative møller uten økonomisk rolle. |
| Damp og industri | Gjenbruk vareflyt og byggoppgradering. Kull, kjele, fabrikk og jernbane som én helhet. | Kull og vann leveres → fabrikk arbeider → varer/skinner flytter raskere. | Drivstofftom, fjern gruve, kapasitet og dag/natt-visning. | Fabrikker før energi-/transportgrunnlag. |
| Elektrisitet og motorisering | Gjenbruk energi-/transportgrensesnitt. Generator, nett og raffinering/motor er to forbundne sløyfer. | Kraftverk → ledninger → lys/maskiner; raffineri → kjøretøy. | Separat kraft-, nett- og forbrukstest; regionalt ujevnt lys. | Magisk global strøm. |
| Luftfart og luftmåling | Gjenbruk kartlag, regioner og planetkamera. | Flyplass/fly gir luftkartlegging, frakt og ærlig sen planetgate. | Drivstoff, flyplass, flyrute, kartpresisjon og ukjent-masking. | Å tolke dagens Luftmåling som ferdig luftfart. |
| Rakettprogram og første bane | Gjenbruk industri, energi, kunnskap, visuell skala og kronikk. | Forsyningskjeder → test → suborbital ferd → romhavn → orbital signal. | Konvergens av seks grener, lagring, mislykket test, vellykket bane og visuell QA. | Å redusere orbit til en teknologiknapp. |

Hver skive er ferdig bare når simulering, autonom handling, brukerretning, synlig verden, lagring ved behov og målrettede normale/grenseflyter fungerer sammen. Etter første orbital ferd dokumenteres solsystemspill separat som **FREMTID**.
