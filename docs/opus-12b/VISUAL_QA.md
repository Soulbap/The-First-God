# OPUS-12B — visuell kvalitetssikring

## Status: PARTIAL

Kode og tester bekrefter at nye bygg går via tomtevalg, respekterer gater/jernbane/terreng og bruker den etablerte painterly renderer-familien.

Forventet synlig følge: bredere, lavere moderne boligvolumer; nye boliger ved gatefront; to små, ikke-vernede hytter som ved reelt press blir én bygård; og mer ekte aktivitet på torget ved middag.

Nye ekte skjermbilder er ikke tatt i denne passeringen. Før PASS må `OPUS_12=1 node tools/capture-gui.mjs http://localhost:5173 docs/opus-12b/shots after` kjøres og moderne by, boligstrøk, tett gate, torg, industri, historie, ombygging og døgnsekvens inspiseres mot OPUS-12.
